# TikTok Downloader – free update

- TikTok short/full URL resolution and embed preview remain supported.
- The TikTok button opens the original post so viewers can use TikTok's official Save video option if the creator allows it.
- A second field accepts a direct `.mp4` URL only for a video the visitor owns or is authorized to download. Cross-origin hosting may open the player rather than force a download.
- This free version does not extract arbitrary TikTok MP4 streams, bypass creator download settings, remove watermarks, or manufacture 1080p quality.

Upload/replace these files in the repository root, keeping the existing `netlify/functions/resolve-tiktok.js` and `netlify.toml` files unchanged. Keep about.html, privacy.html, terms.html and contact.html from the current project.
