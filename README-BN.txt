একটি Render Web Service হিসেবে চালানোর জন্য প্রস্তুত ফাইল।

দ্রুত চালু:
1) ZIP Extract করুন।
2) GitHub repository-র root-এ এই ZIP-এর ভেতরের ফাইল/ফোল্ডার আপলোড করে Commit করুন।
3) Render.com-এ GitHub দিয়ে Sign in করুন।
4) New + → Blueprint নির্বাচন করে এই repository বাছুন।
5) render.yaml শনাক্ত হলে Apply/Deploy করুন।
6) Deploy শেষে Render URL খুলে পরীক্ষা করুন।

গুরুত্বপূর্ণ:
- Render Free service নিষ্ক্রিয় থাকলে sleep করতে পারে; প্রথম request ধীর হতে পারে।
- yt-dlp extraction TikTok-এর পরিবর্তন, দেশ, login, rate limit ও hosting IP-এর কারণে ব্যর্থ হতে পারে।
- এটি কোনো নিশ্চয়তাপ্রাপ্ত অফিসিয়াল TikTok API নয়; সব ভিডিও/HD কোয়ালিটি পাওয়া যাবে না।
- শুধু নিজের বা অনুমতিপ্রাপ্ত ভিডিও ডাউনলোড করুন।
- বর্তমান Netlify URL নিজে থেকে নতুন backend ব্যবহার করবে না; এই প্যাকেজটি Render-এ সম্পূর্ণ আলাদা সাইট হিসেবে deploy হয়।
